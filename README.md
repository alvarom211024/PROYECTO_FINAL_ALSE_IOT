# Proyecto Final ALSE IoT

Sistema de gestión de dispositivos IoT desarrollado en C++ y Qt5.

## Características

- Autenticación de usuarios
- Gestión de dispositivos IoT
- Simulación ONLINE/OFFLINE
- Historial de eventos
- Base de datos SQLite3
- Exportación CSV

## Tecnologías

- C++
- Qt5
- SQLite3
- OpenSSL
